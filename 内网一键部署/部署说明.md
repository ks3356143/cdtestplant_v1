# 内网部署包使用说明

测试管理平台离线一键部署包。目标机器要求：**Windows 10/11 x64，无需安装任何软件、无需管理员权限、无需联网**。

## 快速开始

1. 把整个 `cdtestplant-offline` 文件夹拷到目标机器的**纯英文路径**下，例如 `D:\cdtestplant`。
   注意：MySQL 便携版不支持中文路径，放错位置时一键启动会直接提示，移动后重试即可。
2. 双击 **一键启动.bat**。它会依次拉起：

   | 组件 | 端口 |
   |---|---|
   | MySQL 8.4.3（便携版，含现成数据） | 3307 |
   | Redis 5.0.14（便携版） | 6379 |
   | 后端 waitress（Python 3.13 已内置） | 8000 |
   | nginx 1.28（托管前端页面） | **8181** |

3. 启动完成后会**自动打开登录页**。没弹出来的话，手动访问 `http://127.0.0.1:8181/`。

## 同事怎么访问

部署机上执行 `ipconfig` 查看"IPv4 地址"（例如 192.168.0.50），同事浏览器访问
`http://192.168.0.50:8181/` 即可。

首次启动时 Windows 弹出防火墙提示，勾选"允许访问"；也可在防火墙中放行 8181 端口。

## 停止与重启

- 停止：双击 **一键停止.bat**（nginx、后端、MySQL、Redis 依次干净退出）。
- 重启：再次双击一键启动即可。脚本会**逐个检测四个服务，已在运行的自动跳过、缺哪个补哪个**；
  手动关掉过某个黑窗也没关系，再点一次一键启动就能恢复齐全。

## 目录说明

```
cdtestplant-offline/
├─ 一键启动.bat / 一键停止.bat
├─ 部署说明.md            ← 本文件
├─ python/                ← CPython 3.13 + 全部 Python 依赖（离线可用）
├─ mysql-8.4.3-winx64/    ← 便携 MySQL，data/ 里是打包时的现成业务数据
├─ redis/                 ← 便携 Redis
├─ nginx-1.28.0/          ← 托管前端 + 反向代理，html/dist 是前端产物
├─ app/                   ← 后端源码 + .env 配置 + media 文档模板
└─ dbdata.sql              ← 可选：老基线初始化数据（重置数据用）
```

## 常见问题

- **端口被占**：目标机若已有别的 MySQL 占 3307，改 `mysql-8.4.3-winx64\my.ini` 的 `port` 并同步改 `app\.env` 的 `DATABASE_PORT`；Redis 6379、后端 8000、页面 8181 同理（后端端口改动需同步 `nginx-1.28.0\conf\nginx.conf`）。
- **手工补起 Redis**：Redis 必须带配置文件启动（一键启动已内置）：在 `redis\` 目录执行 `redis-server.exe redis.windows.conf`；裸跑 `redis-server.exe` 在部分 Win10 上会静默退出。
- **LDAP 登录**：默认只走数据库账号（`app\.env` 里 `ENABLE_LDAP_AUTH=false`）。内网能连通公司 AD（dns.paisat.cn:389）时改为 `true` 后重启即可。
- **接口文档 /api/docs 离线打不开**：swagger 页面依赖互联网 CDN 资源，纯内网无法渲染，不影响平台使用。
- **重置数据**：包里带的是打包时刻的完整业务数据；如需回到老基线，可在 `mysql-8.4.3-winx64\bin` 下执行
  `mysql.exe -uroot -proot -P3307 -D chengdu_test_plant_v1 --default-character-set=utf8mb4 < ..\..\dbdata.sql`（会 DROP 重建全部表，注意备份）。
- **更新代码**：开发机重新运行打包脚本生成新的部署包，拷贝覆盖时**不要覆盖目标机的 `mysql-8.4.3-winx64\data` 目录**，否则目标机新产生的数据会丢。
- **脚本窗口显示英文**：两个 bat 的控制台提示刻意用纯英文（cmd 对含中文的批处理解析在部分机器上不稳），中文说明以本文件为准。

## 安全提示

- MySQL root 口令为 `root`，仅限内网封闭环境使用；包内 .env 含应用密钥，请勿外传整个文件夹。
