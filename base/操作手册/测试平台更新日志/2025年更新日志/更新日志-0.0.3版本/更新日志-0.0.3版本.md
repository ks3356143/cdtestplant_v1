## 第一周

1. 【fix-#001】因为修改设计需求的描述（富文本）可以为空，将后端入数据库默认值改为**空字符串**
2. 【New-#001】新增生成文档记录模块，现在仅支持单个用户的日志查询 → 目前仅生成测试项时判断**设计需求的描述是否为空**
3. 【fix-#002】修复在多窗口localStorage变化时候点击确定不刷新浏览器tab页面的问题
4. 【fix-#003】修复在生成回归说明和回归记录时候，项目如果未创建轮次，弹出很多提示的问题，现在只弹出一个并记录在生成日志里面
5. 【fix-#004】如果用户定义项目名称出现window文件夹不允许的字符（/: \*?"<>|），则会导致项目名称和文件无法关联，整个项目生成文档功能报废 → 在前端和后端均对项目名称进行限制
6. 【U-#001】在查询字典时候，如果没有查询到相关字典数据，记录生成文档检查器中，如果错误不报错 → 直接生成文档用空字符串替代
7. 【U-#002】删除项目工作区页面在主页的tab标签，以防止多个tab冲突，在router文件夹新增常量 → const WORK\_AREA\_NAME并加入store/tab-bar文件的BAN\_LIST变量
8. 【Y-#001-后端】更变项目标识，还需要把后端轮次的标识更变
9. 【New-#001】在无关联问题单页面，右键可查看关联用例，并且可以在该页面修改用例
10. 【U-#003】优化右键菜单的显示位置
11. 【U-#004】新增字典serect，项目数据库字段新增secret，现在可以选择对应密级，生成文件使用该密级信息
12. 【U-#005】富文本现在是随着内容自适应不让用户调整高度
13. 【fix-#005-后端】生成测试大纲的测试充分性和有效性章节，因为传入数组而传入字符串导致错误，导致测试类型不正确，现在已修改
14. 【fix-#006-后端】修复生成测评大纲出现重复“术语和缩略语”章节
15. 【New-#002】新增功能-在用例没有设置其中步骤“未通过”时，禁止添加或关联问题单
16. 【New-#003】前端权限系统，规定`role`在userStore储存的为准 → 暂时分为`admin`和`user`两个【后端储存字段】
    1. 普通用户在项目管理页面只能看到自己的项目，无法看到其他人项目

17. 【fix-#007】修复项目页面由于设置样式和属性过多，堆栈溢出问题
18. 【fix-#008】修复浏览器窗口调整后，背景颜色白色不延伸的问题
