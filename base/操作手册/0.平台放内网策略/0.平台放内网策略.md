# 0.平台放内网策略

1. 外网打包前端dist
2. 外网打包后端代码文件夹cdtestplant\_v1（源代码方式注意除了复制media的全部，注意：conf文件夹配置要和内网一致）
3. **注意每次makemigrations后必须打包到内网进行迁移**
4. 前端dist传入内网后，解压到nginx/html文件夹
5. 后端解压覆盖到source文件夹（**注意：env.py修改3307/DEBUG=False**）
6. 注意：如果修改了form\_template文件夹，则放入内网conf以及全部项目的form\_template
7. 注意：如果改动字典数据库必须内网手动添加数据
