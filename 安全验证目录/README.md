# 安全验证目录 —— 内网离线部署包

这里面的 `cdtestplant` 文件夹就是**完整可独立运行的部署包**（约 1.7G，含 Python 运行时、
MySQL、Redis、nginx、后端源码与现成数据）。目标机无需联网、无需安装任何软件、无需管理员权限。

## 怎么交付到内网

1. **拷贝内层的 `cdtestplant` 文件夹**（不是本目录）到内网机器的**纯英文路径**，例如 `D:\cdtestplant`。
   - 文件夹名保持英文不改；路径里不能有中文——MySQL 8.4 便携版不支持中文路径，
     放错了点一键启动会直接提示，移个位置重试即可。
   - 刻光盘只是搬运手段：光盘只读跑不了（MySQL/上传/日志都要写盘），**拷到硬盘再运行**。
2. 双击 `cdtestplant` 里的 **一键启动.bat**，约 1 分钟后自动打开登录页 `http://127.0.0.1:8181/`。
3. 同事访问：部署机上 `ipconfig` 查本机 IPv4，浏览器开 `http://<部署机IP>:8181/`；首次启动防火墙弹窗选"允许"。

登录账号与详细说明见包内 `部署说明.md`（账号 srs_a/srs_b/srs_c/srs_m/srs_o，密码 SrsDemo#2026）。

## 手动验证清单（拷到内网后照着点一遍）

1. **一键启动**：双击 一键启动.bat → 黑窗口走完 5 步 → 浏览器自动开登录页。
2. **普通登录**：srs_m / SrsDemo#2026 → 进工作台，顶栏菜单、统计图正常显示。
3. **特权双因子**：退出，改用 srs_a 登录 → 弹出图形验证码 → 输入后进入 → 项目管理能看到
   R2601「标校软件测试」数据行。
4. **刷新不 404**：在项目管理页按 F5 → 页面原样回来（不是白屏/404）。
5. **文档生成**（平台主业）：R2601 → 工作区 → 文档生成任选一个（如需求追踪表）→ 提示生成成功 →
   能下载打开 docx。
6. **同事机访问**：另一台内网电脑开 `http://<部署机IP>:8181/` → 同样能登录。
7. **一键停止**：双击 一键停止.bat → 几个黑窗口全部退出，浏览器再访问 8181 已打不开。
8. 任何一步卡住：看弹出的对应黑窗口报错，对照 `部署说明.md` 常见问题（端口占用、中文路径、防火墙）。

## 更新代码后重新出包

在开发机项目根执行：

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File 内网一键部署/build_package.ps1
```

会自动重建本目录下的 `cdtestplant`（随机新 SECRET_KEY、字段加密密钥沿用保证历史密文可解）。
拷新包覆盖时**不要覆盖目标机的 `mysql-8.4.3-winx64\data` 目录**（那是目标机业务数据）。
