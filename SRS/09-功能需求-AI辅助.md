# 09 功能需求-AI 辅助

> 后端：`apps/dict/controllers/common.py`（AITestController）；前端：`src/api/outs/aiApi.ts`、设计需求页 AiModal
> 2026-04 新增能力（提交"实现AI生成测试项接口"）

## 1. AI 生成测试项

### 1.1 功能描述

在项目工作区的**设计需求/测试项编写**场景中，通过内网私有化大模型，根据需求描述自动生成**测试项草稿**（测试需求 + 测试子项 + 步骤），减少人工编写量。前端弹窗（AiModal）提交需求上下文与项目类型，返回结构化测试项建议，人工确认后导入。

### 1.2 接口

- `POST /api/local_doc_qa/testing_item`
- 请求体：`{ question: str, project_type: "cpu" | "fpga" }`
- 后端行为：代理转发到内网大模型服务

```
POST http://192.168.0.63:8777/api/local_doc_qa/testing_item
{
  "question": "<需求描述/问题>",
  "model_name": "qwen3.5",
  "project_type": "cpu" | "fpga",
  "streaming": false,
  "user_focus_points": ""
}
```

- 超时：120s；任何 requests 异常统一返回 `ChenResponse(code=502, message="调用大模型接口失败，请联系管理员")`
- 无鉴权（内网服务），响应原样透传给前端

### 1.3 前端交互

- 入口：设计需求页「AI」按钮（AiModal 弹窗）；AI API 基地址由前端环境变量 `VUE_APP_AI_API_BASE` 记录（http://192.168.0.63:8777）
- CPU 与 FPGA 项目类型影响提示词与生成结构（FPGA 支持时序类测试项渲染）

## 2. 约束与风险

1. **内网依赖**：平台部署在内网时可用；外网/隔离环境该功能不可用（按钮可点击但返回 502 提示）
2. AI 生成结果为**草稿**，必须经人工编辑确认后保存；不直接落库
3. 模型名（qwen3.5）与地址为配置硬编码，更换模型需改代码（`model_name # 待变化` 注释）
4. 生成内容不含密级数据外发——question 由用户输入的当前需求文本构成，需注意内网模型服务的数据安全边界
