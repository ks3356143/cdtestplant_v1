# 04 功能需求-项目管理

> 路由：`/testmanage/projmanage`（项目管理列表）、`/projBoard/:projectId`（项目看板）
> 后端：`apps/project/controllers/project.py`（/api/testmanage/project/*）

## 1. 项目管理列表

### 1.1 页面组成

1. **检索区**：项目标识、项目名称、开始时间、结束时间、责任人、人员、状态、关键等级、项目类型、现状、密级
2. **操作按钮**：新建项目、删除
3. **项目表格**：项目标识、项目名称、开始日期、结束时间、责任人、报…、操作；分页（10 条/页）
4. **行内操作**：文档生成、工作区、复制、历史、参数、编辑、看板、（勾选）删除

### 1.2 功能需求

| 编号 | 需求 | 接口 |
|---|---|---|
| PM-01 | 项目列表查询（支持多条件过滤） | GET /api/testmanage/project/index |
| PM-02 | 新建项目（表单：标识唯一、三方信息、级别/类型/密级等，见数据模型） | POST /api/testmanage/project/save |
| PM-03 | 编辑项目 | PUT /api/testmanage/project/update/{project_id} |
| PM-04 | 删除项目（级联删除轮次/被测件/需求/用例/问题） | DELETE /api/testmanage/project/delete |
| PM-05 | 进入工作区（清除本地树缓存后跳转 /project?id=…） | 前端路由跳转 |
| PM-06 | 打开项目看板 | GET /api/testmanage/project/board（看板聚合数据） |
| PM-07 | 文档生成弹窗（见 06 文档） | 见 06 |
| PM-08 | 项目信息完成度（生成分步引导/进度） | GET /api/testmanage/project/project_info_status/ |
| PM-09 | 项目信息单条查询 | GET /api/testmanage/project/findOneById/{id} |

### 1.3 项目编辑表单字段（分组）

- **基本信息**：项目标识（唯一）、项目名称、开始/结束时间、负责人、项目成员（多选）、质量保证员、质量监督员、配置管理员
- **级别与类型**：安全等级、测试级别（多选）、平台类型（多选）、报告类型（鉴定/第三方）、被测语言（多选）、依据标准（多选，含文档名与发布日期）、密级、软件类型（新研/改造/沿用）
- **三方信息**：委托方（单位/联系人/电话/邮箱）、研制方（单位/联系人/电话/邮箱）、测试方/测评中心（单位/联系人/电话/邮箱）
- **环境**：运行环境（多选）、开发环境（多选）
- **阶段**：项目阶段（进行中/已完成/已废弃）

### 1.4 校验规则

1. 项目标识唯一（数据库 unique）
2. 项目结束时间不得早于最后一个轮次的结束时间（违反返回专用错误码 500412，前端弹出 HttpError 提示）
3. 删除项目为级联删除（轮次、被测件、设计需求、测试项、用例、问题单、文档素材均随外键删除），需二次确认

## 2. 项目看板（/projBoard/:projectId）

### 2.1 页面组成（自上而下）

1. **标题栏**：R 编号 + 项目名称 + 状态徽章（进行中/已完成/已废弃）
2. **概览统计**（5 组）：
   - 时间：开始时间、预结束时间、距结束天数
   - 人员：负责人、共有数（成员数）
   - 开发方信息：联系人、电话、邮箱
   - 用例数：总数、已执行、未执行、服务执行
   - 问题数：总数、已闭环、未闭环
3. **项目时间轴**：项目开始时间 → 各轮次（第 N 轮次、起止时间、项目执行节点）→ 基线时间；支持提示"自定义文档生成的日历"（文档时间展示 `GET /api/testmanage/project/document_time_show`）
4. **测试类型统计表**：按测试类型汇总 测试项数/测试用例数/问题数
5. **第 N 轮次信息**（每轮一个区块）：设计需求/测试项/用例统计信息（按类型：功能化、静态分析、代码审查、文档审查等），附每类 测试项数/测试用例数/问题数

### 2.2 功能需求

| 编号 | 需求 | 接口 |
|---|---|---|
| PB-01 | 看板聚合数据（统计 + 时间轴） | GET /api/testmanage/project/board |
| PB-02 | 文档时间展示 | GET /api/testmanage/project/document_time_show |
| PB-03 | 从看板快捷进入各轮次编写区（时间轴/轮次块点击） | 前端路由 |

## 3. 项目复制与树复制

- **复制项目**：行内"复制"整项目复制（含数据）为新项目
- **子树复制**：`POST /api/treeOperation/copy` 支持在工作区复制任意子树（轮次/被测件/设计需求/测试项/用例）到目标节点，后端重排 key
- **接口方向切换/复制当前**：设计需求支持 `GET /api/project/switch_position`、`GET /api/project/copy_current`
