# 08 功能需求-日志监控

> 路由：`/monitor/*`（仅 admin 角色可见）；后端：`apps/system/controllers/log.py` + `apps/user/controllers.py`（日志部分）+ `utils/log_util/`
> 三类日志页共用查询/删除模式，均为 admin 权限

## 1. 数据操作日志（/monitor/operationLog）

记录**业务数据级**的操作（谁对哪张表的哪条数据做了什么）。

- 存储：`operation_log` 表（TableOperationLog）：创建时间、操作人员（外键 Users）、操作对象 operate_obj、操作详情 operate_des
- 由各业务写操作在事务内主动写入（如树节点增删改、问题单状态变更等）

| 功能 | 接口 |
|---|---|
| 列表 | GET /api/system/log/operations |
| 分页列表 | GET /api/system/log/operationsPagination |
| 删除（清理） | GET /api/system/log/operationsDel（IsAdminUser） |

## 2. 接口操作日志（/monitor/operations）

记录**HTTP 请求级**的访问（所有 /api 请求的方法、路径、参数、来源、结果）。

- 采集：`ApiLoggingMiddleware`（settings.py 中间件）对请求统一记录；同时输出到日志文件 `logs/root_log`
- 存储：`system_operation_log` 表（OperationLog）：请求用户、请求模块（按路径映射 API_MODEL_MAP）、请求地址、请求参数（body）、请求方式、操作说明、请求 IP、浏览器、操作系统、响应状态等；排除路径由 API_OPERATION_EXCLUDE_START 配置
- 前端页面：模块筛选、用户筛选、时间范围、关键字检索，可查看请求参数详情

| 功能 | 接口 |
|---|---|
| 列表 | GET /api/system/log/list |
| 操作日志列表 | GET /api/system/log/operations（同 1 共用） |

## 3. 登录日志（/monitor/loginLog）

- 存储：`system_login_log` 表（LoginLog）：登录用户名、IP、User-Agent、浏览器、操作系统、国家/归属地（ENABLE_LOGIN_ANALYSIS_LOG 开启时通过在线 API 解析 IP 归属地）、登录类型（普通登录）、描述
- 写入时机：每次 POST /api/system/login（成功/失败均留痕，失败记录到 remark）

| 功能 | 接口 |
|---|---|
| 列表 | GET /api/system/log/loginLogsList |
| 删除 | GET /api/system/log/loginLogsDel（IsAdminUser） |

## 4. 日志监控页面通用需求

1. 仅 admin 角色可见（前端路由 roles=["admin"]，菜单「日志监控」）
2. 分页 + 筛选（时间范围、用户、模块、关键字）
3. 删除操作需确认且仅 admin（后端 IsAdminUser）
4. 接口日志用于审计与排障：请求参数完整留存（注意密级项目数据同样落库，生产环境应控制库访问权限）
