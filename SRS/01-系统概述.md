# 01 系统概述

## 1. 系统定位

测试管理平台（TestManagePlant）是面向**软件测评中心**的测评过程管理 + 测评文档自动生成系统。它覆盖一次软件测评从立项、编制测试需求与用例、执行测试、问题闭环，到最终输出全套交付文档（测评大纲、测试说明、测试记录、测评报告、回归测试文档、问题单等）的完整业务链。

系统支持"鉴定测试"与"第三方测试"两种报告类型（由项目 `report_type='9'` 区分），并按 CPU / FPGA 两类被测对象提供差异化的字段与文档渲染（如 FPGA 时序图、CPU 测试子项描述）。

## 2. 总体架构

```
┌────────────────────────────────────────────────┐
│  浏览器                                         │
│  Vue 3 SPA（web/cdTMP，端口 3888 开发 / Nginx 生产）│
└──────────────┬─────────────────────────────────┘
               │ /api 代理（vite proxy / nginx 反代）
┌──────────────▼─────────────────────────────────┐
│  后端 API 服务（端口 8000）                       │
│  Django 6 + django-ninja(-extra/-jwt)           │
│  apps/: user, dict, system, project,            │
│         createDocument, createSeiTaiDocument    │
└───┬──────────────┬─────────────────────────────┘
    │              │
┌───▼─────┐   ┌────▼─────┐   ┌──────────────────┐
│ MySQL   │   │ Redis    │   │ 内网 AI 服务      │
│ 8.4     │   │ 6379     │   │ 192.168.0.63:8777│
│ 业务数据 │   │ 缓存     │   │ qwen3.5 文档问答  │
└─────────┘   └──────────┘   └──────────────────┘
```

- 认证：JWT（django-ninja-jwt），认证后端 = LDAP（内网 AD 域 `dns.paisat.cn`）+ Django ModelBackend（本地库用户）
- 文档生成：python-docx / docxtpl / docxcompose / lxml，直接在服务端生成 .docx
- 文件存储：`media/R{项目标识}/` 目录（模板、临时片段、最终文档），`uploads/` 上传目录
- 生产打包：PyInstaller + waitress（`run.py`、`run.spec`），数据库/Redis/Nginx 以绿色版随包部署（`packagesInitialize/`）

## 4. 部署形态

### 4.1 开发环境

- 后端：`uv run python manage.py runserver`（dev_settings，DEBUG=True，MySQL 127.0.0.1:3306）
- 前端：`npm run dev`（Vite，端口 3888，`/api` 代理到 `http://127.0.0.1:8000/api`）
- MySQL / Redis 使用 `packagesInitialize/` 下绿色版（启动脚本 `mysql_start.bat`、`redis-server.exe --port 6379`）

### 4.2 生产环境（内网）

- `run.py`：waitress WSGI 服务（127.0.0.1:8000），PyInstaller 打包为 run.exe
- `packagesInitialize/`：nginx-1.28.0（静态资源与反代）、mysql-8.4.3 绿色版（生产端口 **3307**）、`启动系统.vbs` 一键启动
- 数据库生产配置：`conf/env.py`（数据库 3307、Redis、LDAP）；打包需移除 settings.py 中 staticfiles/TEMPLATES 调试项（TODO 已标注）
- 初始化数据：`packagesInitialize/dbdata.sql`（43 张表，可重复导入）

## 5. 用户角色（三权分立）

| 角色 | 判定 | 能力 |
|---|---|---|
| 普通用户 | `user.role='user'` | 工作台、项目全流程操作 |
| 系统管理员 | `user.role='admin'` | 账号管理、字典与业务运维配置；**无**安全策略/标记/审计权限 |
| 系统安全员 | `user.role='secadmin'` | 安全策略（登录锁定阈值）、用户密级标记管理（/security/policy）；**无**账号/运维/审计权限 |
| 系统审计员 | `user.role='auditadmin'` | 日志监控（数据操作/接口/登录日志、统一安全审计、抗抵赖证据）；**无**配置修改权限 |

- 权限判定：`utils.permissions` 权限类（IsSystemAdmin/IsSecurityAdmin/IsAuditor，按 role 判定），前端路由 `meta.roles` 控制菜单可见性（GB/T 28452-2012 7.1.5）
- 登录方式：账号密码（LDAP 优先，域不可达回落本地库），特权角色需图形验证码，JWT 有效期由 `TOKEN_LIFETIME` 控制
