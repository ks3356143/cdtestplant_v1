# 用户手册生成器

《SRS/测试管理平台软件用户手册.docx》由本目录脚本生成，改内容后重跑即可，不要直接手改 docx。

## 用法

```bash
bash SRS/用户手册生成/rebuild.sh
```

脚本从 `SRS/参考/参考记录.docx` 复制模板、清空正文，按模板样式重建全文，回填总页数后输出到
`build/manual-work.docx`，确认无误后复制为 `SRS/测试管理平台软件用户手册.docx`。

## 目录

| 文件 | 说明 |
|---|---|
| `manual_content.py` | 正文内容块（1 范围 ~ 6 注解） |
| `build_manual.py` | 编译为 officecli batch（封面、目录、标题、段落、表格、图片） |
| `rebuild.sh` | 一键重建 |

图片复用 `SRS/用例文档生成/img/` 下的线上截图（711.png、713a.png、716.png 等）。

## 结构（GJB 438B-2009《软件用户手册》）

```
1 范围          1.1 标识 / 1.2 系统概述 / 1.3 文档概述
2 引用文件
3 软件概述      3.1 软件功能 / 3.2 软件运行环境 / 3.3 软件结构与配置
4 使用指南      4.1 软件的安装与卸载（安装/卸载/升级）
                4.2 软件的启动与退出
                4.3 软件的操作说明
                    4.3.1 界面说明
                    4.3.2 列表页与表单页通用操作
                    4.3.3 登录与注销
                    4.3.4 工作台与个人中心
                    4.3.5 用户管理
                    4.3.6 项目管理
                    4.3.7 项目工作区
                    4.3.8 文档生成
                    4.3.9 数据管理（字典/联系信息/缩略语/备份/文档片段）
                    4.3.10 日志监控
                    4.3.11 安全策略
                    4.3.12 AI 辅助生成测试项
                4.4 典型业务场景（场景一~场景五）
5 出错处理和恢复
6 注解          6.1 缩略语 / 6.2 术语
```

`rebuild.sh` 末尾会调用 `SRS/tools/clean_docx_parts.py`，删除模板残留的未引用页眉/页脚部件，
避免旧项目标题留在文档包内并减小文件体积。
