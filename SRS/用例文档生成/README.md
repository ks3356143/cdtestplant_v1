# 安全测评测试记录生成器

《SRS/安全测评测试记录（含执行结果）.docx》由本目录的脚本生成，改动内容后重跑即可，不要直接手改 docx。

## 用法

```bash
bash SRS/用例文档生成/rebuild.sh
```

脚本会从 `SRS/参考/参考记录.docx`（客户模板）复制一份、清空正文，再按模板的样式与自动编号重建全文，
最后回填总页数，输出到 `build/工作副本.docx`；确认无误后复制为 `SRS/安全测评测试记录（含执行结果）.docx`。

依赖 [officecli](https://github.com/iOfficeAI/OfficeCLI) 与 Python 3。

## 目录

| 文件 | 说明 |
|---|---|
| `build_doc.py` | 生成 officecli batch 命令流：封面、目录、1 范围、2 测试记录（10 条款 / 56 用例） |
| `data/7xx.json` | 每个条款一个数据文件：要求摘要、实现状态、用例（名称/标识/追踪关系/综述/初始化/前提/步骤） |
| `strip.json` | 清空模板正文的 batch 命令（98 表格 + 252 段落，从后往前删） |
| `img/` | 界面截图证据，按条款放置（7.1.3 两张，其余各一张） |
| `rebuild.sh` | 一键重建：清空 → 填内容 → 行不跨页/表头重复 → 标题左对齐 → 回填页数 |

## 表格结构（与模板一致）

每条用例一张 11 列网格表：

```
记录N（自动编号）
测试用例名称 | 值 | 标   识 | 值
追踪关系 | 值
测试用例综述 | 值
用例初始化 | 值
前提和约束 | 值
测试步骤
序号 | 输入及操作 | 期望结果与评估标准 | 实测结果 | 通过与否
1    | …          | …                  | …        | 通过
```

## 改内容

只改 `data/*.json` 里的 `cases[].steps[]`，每个步骤四项：`op`（输入及操作）、`exp`（期望结果与评估标准）、
`act`（实测结果）、`pass`（通过 / 不通过 / 不适用）。实测结果须来自真实执行记录
（`C:\Users\31429\captcha_test\cases_result.json`），不要凭空编写。

## 注意

- 模板的用例标题编号是 `numId=25`（显示为「记录N」），跨表连续编号，不要在数据里手写编号。
- 目录是 TOC 域，Word 打开时按 `updateFields` 自动刷新；LibreOffice 预览会显示占位提示。
- 总页数由脚本调用 Word 重排版统计后写入，换机器排版可能差一页，属正常。
