# 07 功能需求-数据管理

> 路由：`/datamanage/*`；后端：`apps/dict/controllers/`（dict.py、contact.py、abbreviation.py、fragment.py、common.py）
> 所有接口挂在 `/api/system` 前缀下，均需 JWT 认证

## 1. 数据字典（/datamanage/dictmanage）

两级结构：**字典类（Dict）→ 字典项（DictItem）**。左侧字典类列表，右侧字典项维护（DataList）。

### 1.1 字典类

| 功能 | 接口 |
|---|---|
| 字典类列表 | GET /api/system/dataDict/index |
| 启用/禁用字典类 | PUT /api/system/dataDict/changeStatus（IsAdminUser） |

### 1.2 字典项

| 功能 | 接口 |
|---|---|
| 按字典查项 | GET /api/system/dataDict/list?code={字典code} |
| 全部启用项（下拉用） | GET /api/system/dataDict/dictItemAll |
| 新建项 | POST /api/system/dataDict/saveitem |
| 快速新建（表格内联） | POST /api/system/dataDict/fastSave |
| 保存标准项（带文档来源） | POST /api/system/dataDict/saveStdItem |
| 编辑项 | PUT /api/system/dataDict/update/{id} |
| 启用/禁用项 | PUT /api/system/dataDict/changeItemStatus（IsAdminUser） |
| 上移/下移排序 | PUT /api/system/dataDict/numberOperation |
| 删除项 | DELETE /api/system/dictType/realDeleteItem（IsAdminUser） |

### 1.3 字典项字段

title（显示名称）、key（实际值，提交给后端）、show_title（类型转文字）、status（启用/禁用）、sort（排序）、remark；依据标准类字典额外有 doc_name（文档名称）、publish_date（发布日期）、source（来源）。

### 1.4 系统内置字典（22 类）

data_status、report_type（报告类型）、step（项目阶段）、security_level（安全等级）、test_level（测试级别）、plant_type（平台类型）、language（被测语言）、standard（依据标准）、demandType（设计需求类型）、priority（优先级）、testType（测试类型，22 项）、passType（通过状态）、execType（执行状态）、problemStatu（问题状态）、problemType（问题类型）、problemGrade（问题等级）、closeMethod（闭环方式）、testMethod（测试方法）、runtime（运行环境）、devplant（开发环境）、secret（密级）

> 枚举值详见 [附录-数据字典枚举](13-附录-数据字典枚举.md)。字典值被项目表单、需求/用例/问题的类型字段、文档渲染共同引用，修改需谨慎（管理员操作 + 二次确认）。

### 1.5 缓存

字典读取走 Redis 缓存（CACHES db1），变更后失效刷新；Redis 不可用时相关下拉接口报错。

## 2. 项目联系信息（/datamanage/projContact）

维护**单位信息库**（contact_gongsi），供建项目时快速选择委托方/研制方/测试方单位与联系人。

- 字段：公司名称 name、公司简称 refer_name、法人 entrust_person、公司编号 key、公司地址 addr
- 接口：

| 功能 | 接口 |
|---|---|
| 检索 | GET /api/system/contact/getlist |
| 全量 | GET /api/system/contact/index |
| 新建 | POST /api/system/contact/save |
| 编辑 | PUT /api/system/contact/update/{id} |
| 删除 | DELETE /api/system/contact/delete |

## 3. 缩略语（/datamanage/abbreviation）

维护**缩略语/行业词汇库**（project_abbreviation），供建项目时勾选（项目表 abbreviation JSON 字段），并渲染进测评大纲"缩略语"章节。

- 字段：title（缩略语）、des（描述）
- 接口：GET /api/system/abbreviation/getlist（检索）、/index（全量）、POST /save、PUT /update/{id}、DELETE /delete

## 4. 文档片段管理（/projFragment 页面，见 06 文档）

同属数据管理范畴的富文本片段库（fragment_core），按项目隔离，接口 /api/system/userField/*。
