## V0.1.2 安全测评增强（2026-10-15 ~ 2026-10-19）

依据《GB/T 28452-2012 应用软件系统安全测评规范》第三级要求逐条实现并验证
（需求追踪见 `SRS/安全测评要求实现追踪表.docx`，设计说明见 `SRS/` 目录）：

- **7.1.1 用户身份鉴别**：口令 + 特权角色图形验证码双因子；连续失败锁定（阈值由安全员配置）；登录日志与告警留痕
- **7.1.2 抗抵赖**：项目关键操作（创建/授权/用例与问题单证据挂钩）生成抗抵赖证据（SHA-256 摘要 + 内容快照），审计员专用核验页
- **7.1.3 自主访问控制**：项目级授权（负责人/成员/管理员三层，约 40 个路由收敛检查）；撤销立即生效；成员不可自我提权
- **7.1.4 敏感标记**：用户密级许可（1公开~5绝密）与项目密级（secret 字典）；"不上读"强制——低许可用户无法访问高密级项目
- **7.1.5 强制访问控制**：三权分立（系统管理员/安全员/审计员权责隔离，`utils/permissions.py`）；标记由安全员统一授予（安全策略页）；无全能账号
- **7.1.6 安全审计**：统一审计日志（`system_audit_log`，10 类核心安全事件全覆盖、含 IP、仅追加防篡改）；统一安全审计页（多维检索+告警高亮）；日志 30 天保留期保护，全清拒绝并告警
- **7.1.7 完整性**：项目/用例/用例步骤/问题单关键字段生成 SHA-256 完整性标记，数据变更自动重算；审计员核验页可一键核查全库标记一致性
- **7.1.8 保密性**：用户电话/邮箱落库透明加密（Fernet，密钥经环境变量注入，历史数据就地加密迁移，另建 SHA-256 盲索引供等值检索）；登出即清服务端临时键、临时文件按保留期清理、日志落库前统一脱敏；传输加密由部署层 TLS 反代承担（`deploy/https`）
- **7.1.9 备份与故障恢复**：按项目范围或全量备份业务数据（26 张表导出 JSON + SHA-256 摘要），恢复前校验摘要、按主键 upsert 可重复执行；支持增量备份（只带水位线后新增/变更），`manage.py auto_backup` 供计划任务定时调用；「数据管理-数据备份与恢复」页可新建/恢复/下载/删除
- **7.1.10 系统安全性检测分析**：一键自检覆盖操作系统/数据库/网络/应用系统/硬件五类被测对象，逐项给出结论与整改建议，应用层之外如实标注承担方；检测动作写统一审计。依据检测结论已整改 4 项（其中未鉴别的对外接口由 88 个收敛为登录/验证码/令牌刷新/一次性下载令牌 4 个入口），见「安全策略-安全性检测分析」页
